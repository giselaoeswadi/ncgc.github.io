Melestarikan yang didorong oleh sebuah narasi fiksi ilmiah yang kuat.

•	Visi dan Misi: Proyek ini bertujuan untuk memberikan kehidupan yang lebih baik dan
terbarukan dengan membangun Pusat Pelestarian Alam dan Pengelolaan Limbah.

•	Konsep Cerita: Proyek ini berlatar belakang tahun 2100, di mana Bumi berada dalam
kondisi kritis. Sebuah tim ilmuwan menemukan kembaran Bumi, yaitu Planet Verda.
Misi utama para pengunjung website (disebut sebagai Team Explorasi Antar Galaksi)
adalah merancang dan membangun kembali kehidupan baru di Planet Verda
menggunakan teknologi yang telah diperbarui.

•	Fokus Edukasi: Proyek ini menyajikan tiga pilar utama pentingnya pelestarian
lingkungan: Pengelolaan Sampah, Pengelolaan Udara Bersih, dan Transportasi Ramah
Lingkungan.

LATAR BELAKANG PROYEK ECOPLANET
Pada tahun 2100, Bumi berada dalam kondisi kritis akibat pencemaran, ledakan populasi, kerusakan ekosistem, serta kegagalan sistem pengelolaan lingkungan. Dalam keadaan genting ini, sekelompok ilmuwan menemukan sebuah planet baru bernama Planet Verda, yaitu kembaran Bumi yang masih alami dan memiliki potensi besar untuk kehidupan baru umat manusia.
Website EcoPlanet dibangun sebagai simulasi dan media edukasi mengenai upaya manusia membangun peradaban baru di Planet Verda. Para pengunjung website diposisikan sebagai:

Tim Eksplorasi Antar Galaksi
Mereka bertugas untuk:
•	mengeksplorasi Planet Verda,
•	merancang sistem kehidupan baru,
•	menjalankan misi pelestarian lingkungan,
•	memanfaatkan teknologi baru seperti AI, sensor data, energi terbarukan, dan transportasi ramah lingkungan.
Website ini menggunakan pendekatan edukasi berbasis cerita (story-based learning) dengan tiga pilar utama:
1.	Pengelolaan Sampah Cerdas
2.	Pengelolaan Udara Bersih
3.	Transportasi Ramah Lingkungan
Melalui visual futuristik, animasi, dan game Scratch yang terintegrasi, EcoPlanet mengajak generasi muda memahami pentingnya membangun masa depan yang berkelanjutan.

FITUR UTAMA WEBSITE ECOPLANET
Berikut daftar fitur berdasarkan kode pada file index.html dan konsep proyek.
1) Hero Section Interaktif Bertema Antariksa
Dilengkapi elemen:
•	Latar belakang bintang bergerak (stars animation)
•	Roket animasi naik–turun (CSS floatUp)
•	Planet futuristik Verda
•	Judul dan subjudul bertema eksplorasi
Tujuan fitur:
Mengenalkan dunia fiksi EcoPlanet dengan visual yang menarik dan imersif.

2) Latar Belakang Misi (Mission Section)
Menjelaskan cerita tahun 2100 dan penemuan Planet Verda dalam bentuk teks edukatif dan tombol ajakan (CTA).
Tujuan fitur:
Mengarahkan pengguna memahami alasan proyek ini ada.

3) Info Section “Kenapa Penting?”
Terdiri dari 3 kartu edukasi utama:
1. Pabrik Pengelolaan Sampah dengan AI
2. Sistem Pengelolaan Udara Bersih
3. Transportasi Ramah Lingkungan
Setiap kartu memiliki:
•	gambar,
•	deskripsi singkat,
•	efek hover memperbesar.
Tujuan fitur:
Memberikan pengetahuan dasar mengenai pilar pelestarian lingkungan.

4) Game Edukasi Petualangan (Game Section)
Tiga game Scratch yang relevan:
•	Petualangan Luar Angkasa
•	Teknologi Pemilah Sampah
•	Selamatkan Air
Setiap kartu game menggunakan Flip Card 3D:
•	Depan menampilkan preview game
•	Belakang berisi cerita game
Klik kartu akan memunculkan popup game (iframe).
Tujuan fitur:
Memberikan pengalaman belajar interaktif, bukan hanya membaca teori.

5) Game Popup
Saat user memilih game, sebuah popup fullscreen akan menampilkan game Scratch.
🔥 Tujuan fitur:
Membuat pengalaman bermain lebih fokus.

6) Formulir “Gabung Misi”
Formulir pendaftaran untuk pengguna yang ingin bergabung dengan misi eksplorasi Planet Verda.
 Tujuan fitur:
Mengajak pengguna berpartisipasi lebih dalam.

7) Footer Sosial Media dan Kontak
Menampilkan:
•	Instagram
•	Scratch
•	GitHub
•	Codedex
•	Kontak organisasi
Tujuan fitur:
Memperkuat kredibilitas dan memberi akses komunikasi.

LANGKAH-LANGKAH PEMBUATAN WEBSITE ECOPLANET
Berikut langkah pembuatan berdasarkan struktur kode yang Anda unggah.

Langkah 1 — Merancang Konsep & Storyline
1.	Menentukan tema: Eksplorasi – Membangun – Melestarikan
2.	Mengembangkan cerita fiksi ilmiah tentang tahun 2100.
3.	Menetapkan tiga pilar edukasi lingkungan.
4.	Mendesain alur pengunjung sebagai “Team Explorasi Antar Galaksi”.
5.	

Langkah 2 — Mendesain Tampilan
1.	Menentukan gaya futuristik antariksa.
2.	Mengatur skema warna: hijau, biru, kuning, dan warna space-galaxy.
3.	Mendesain elemen visual seperti:
o	roket,
o	planet,
o	bintang,
o	kartu informasi,
o	flip card untuk game.

Langkah 3 — Membuat Struktur HTML
Pada file index.html dibuat struktur berikut:
•	<header> → navigasi
•	<section class="hero"> → halaman utama
•	<section class="mission-section"> → latar belakang misi
•	<section class="info-section"> → pilar edukasi
•	<section class="game-section"> → game edukatif
•	<section id="gabung"> → form pendaftaran
•	<footer> → kontak & sosial media

Langkah 4 — Membuat Styling CSS
Fitur CSS yang digunakan:
1. Animasi Roket
Menggunakan @keyframes floatUp.
2. Animasi Bintang
Background bergerak menggunakan @keyframes moveStars.
3. Planet Glow
Menggunakan radial gradient dan shadow neon hijau.
4. Flip Card 3D
Memakai:
transform-style: preserve-3d;
transform: rotateY(180deg);
5. Responsiveness
Media Query @media(max-width: 768px) untuk tampilan mobile.

Langkah 5 — Menambahkan Game Scratch
Menggunakan iframe:
<iframe src="https://scratch.mit.edu/projects/...embed"></iframe>
Popup game dibuat dengan:
•	CSS overlay,
•	JavaScript untuk openGame() dan closeGame().

Langkah 6 — Integrasi Javascript
Script digunakan untuk:
1.	Membuka popup game dengan URL dinamis.
2.	Menutup popup dan reset iframe.
3.	Mengambil URL game dari flip-card secara otomatis.

Langkah 7 — Testing & Optimasi
1.	Cek tampilan desktop & mobile.
2.	Pastikan animasi halus.
3.	Menjamin game dapat dibuka.
4.	Menguji navigasi.
5.	Optimasi gambar dan ukuran file.
