🌍 EcoPlanet — Eksplorasi, Membangun, dan Melestarikan

Website Edukasi & Game tentang Pelestarian Lingkungan Berbasis Cerita Futuristik

🏆 Tentang Proyek

Kategori: Web Design & Game Edukasi
Kompetisi: National Coding & Game Championship 2025
Oleh: Gisela Margaret Elysia Oeswadi
Sekolah: SMP Xaverius 6 Palembang
Kelas: VIII

EcoPlanet adalah proyek website futuristik yang menggabungkan edukasi lingkungan, visual interaktif, dan game Scratch dalam satu pengalaman eksplorasi antariksa. Website ini dibuat sebagai simulasi perjalanan manusia di tahun 2100 untuk membangun peradaban baru di planet bernama Verda—kembaran Bumi yang masih alami.


DOKUMENTASI PROYEK WEBSITE FINAL

🪐 Latar Belakang Proyek

Pada tahun 2100, Bumi mengalami krisis parah akibat:

Pencemaran lingkungan

Kerusakan ekosistem besar-besaran

Ledakan populasi

Gagalnya sistem pengelolaan limbah dan udara

Dalam kondisi genting ini, ilmuwan menemukan planet baru bernama Planet Verda. Proyek EcoPlanet mengajak pengunjung menjadi “Tim Eksplorasi Antar Galaksi” untuk:

Menjelajahi Planet Verda

Mendesain sistem kehidupan baru

Menjalankan misi pelestarian lingkungan

Menggunakan teknologi masa depan: AI, energi terbarukan, sensor udara, dan transportasi hijau


DOKUMENTASI PROYEK WEBSITE FINAL
